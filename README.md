# FoodMaxxing

FoodMaxxing — веб-сервис и терминал оперативного управления экспресс-выдачей блюд и кухней (JIT KDS / Smart Cafeteria) для университетских столовых, корпоративных кафетериев и фудкортов.

Проект решает проблему очередей во время обеденных пиков, синхронизируя время приготовления блюд строго под желаемое время прихода посетителя (Just-in-Time scheduling).

---

## Ключевые возможности

### 1. Клиентский интерфейс (Витрина и заказ)
* **Каталог блюд с фильтрацией:** категории (Горячие блюда и бургеры, Пицца и выпечка, Закуски и гарниры, Напитки и кофе).
* **Пищевые критерии:** фильтры по сертификации Халяль, вегетарианским блюдам и хитам продаж.
* **Выбор интервала выдачи (JIT Time Slots):** динамический расчет доступности временных слотов с учетом загрузки кухонных цехов.
* **Авторизация по номеру телефона (SMS):**
  * Маска ввода телефона `+7 (xxx) xxx xx xx`.
  * Обязательное согласие с Политикой конфиденциальности.
  * Персональная история заказов, изолированная строго для каждого номера телефона.
* **Экран отслеживания заказа:** статус готовности, таймер, детали состава и полка выдачи.
* **Цифровой пасс-билет (Passcard):** QR-код для моментального сканирования на стойке выдачи (получение до 30 секунд).
* **Электронный чек:** просмотр реквизитов, сумм и отправка деталей через WhatsApp.

### 2. Кухонный экран (Kitchen Display System — KDS)
* **Динамическое название заведения:** отображение и возможность редактирования названия прямо на экране (с сохранением и синхронизацией).
* **3-колоночный трекер приготовления:**
  1. *Запланировано (Scheduled):* автоматический обратный отсчет до момента старта готовки.
  2. *Готовится (Cooking):* индикация цеха (гриль, фритюр, печь, холодный цех, кофе-бар), управление задержками (+5 минут).
  3. *Готово к выдаче (Ready):* назначение полок и ячеек выдачи, подтверждение передачи гостю.
* **Телеметрия выдачи:** фиксация времени ожидания гостя у стойки.
* **Вкладка «Меню заведения»:**
  * Управление стоп-листом (переключатель «В наличии» / «В стоп-листе» в один клик).
  * Поиск и удаление позиций.
  * Окно добавления нового блюда: установка названия, описания, цены (KZT), цеха приготовления, калорийности, времени готовки, критериев (Халяль, Вег, Хит) и фотографии (загрузка файла с устройства, прямая ссылка URL или выбор из пресетов).

### 3. Архитектура и технологии
* **Frontend:** React 18, TypeScript, Tailwind CSS, Lucide Icons, Vite.
* **База данных и синхронизация:** Supabase Realtime (PostgreSQL) с поддержкой мгновенных оповещений без задержек.
* **Локальный режим (Offline/Fallback):** полноценная работа через LocalStorage при отсутствии подключения к базе.
* **Мультиязычность:** казахский (ҚАЗ), русский (РУС), английский (ENG).
* **Безопасность:** строгая изоляция данных и заказов по телефонным номерам.

## Быстрый старт

### Требования
* Node.js версии 18 или новее.
* Менеджер пакетов npm.

### Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/<ваш-аккаунт>/<ваш-репозиторий>.git
cd <ваш-репозиторий>
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите проект в режиме разработки:
```bash
npm run dev
```
Сервис откроется по адресу: `http://localhost:3000`.

4. Сборка для продакшена:
```bash
npm run build
```
Собранные оптимизированные файлы будут в каталоге `dist/`.

## Настройка базы данных (Supabase)

Для синхронизации кухни и клиентов между разными устройствами и браузерами:

1. Создайте проект на [Supabase](https://supabase.com).
2. Откройте **SQL Editor** и выполните скрипт из файла `supabase_schema.sql`.
3. Создайте файл `.env` в корне проекта:
```env
VITE_SUPABASE_URL=https://ваш-проект.supabase.co
VITE_SUPABASE_ANON_KEY=ваш-anon-публичный-ключ
```
4. Перезапустите приложение.
